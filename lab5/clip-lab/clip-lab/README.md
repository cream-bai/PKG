# Лабораторная работа 5 — Алгоритмы отсечения отрезков и многоугольников

## Описание

Веб-приложение для визуализации алгоритмов отсечения отрезков и многоугольников.

## Структура проекта

```
clip-lab/
├── index.html              # Главная страница
├── css/
│   └── style.css           # Стили
├── js/
│   ├── geometry.js         # Геометрические примитивы и операции
│   ├── algorithms.js       # Алгоритмы отсечения
│   ├── spatial.js          # Пространственные структуры (AABB, Quadtree)
│   └── app.js              # Главное приложение
├── example_input.txt       # Пример входного файла
└── test.js                 # Модульные тесты (node test.js)
```

## Алгоритмы

### Отрезки:
1. **Сазерленд-Коэн** — структурный алгоритм с 4-битными кодами регионов
2. **Лианг-Барски** — параметрический алгоритм (оптимальный)
3. **Алгоритм средней точки** — рекурсивный алгоритм
4. **Сайрус-Бек** — параметрический для произвольного выпуклого отсекателя

### Многоугольники:
1. **Уайлер-Атертон** — для произвольных (в т.ч. вогнутых) полигонов
2. **Грейнер-Хорман** — улучшенный алгоритм для выпуклых полигонов

## Особенности

- ε-устойчивость (precision epsilon = 10⁻⁷)
- AABB пре-фильтрация
- Quadtree для больших объёмов данных (500K+ отрезков)
- Обработка вырожденных случаев (границы, точки, вершины)
- Интерактивное управление мышью
- Статистика арифметических операций
- Бенчмарк алгоритмов

## Запуск

Просто откройте `index.html` в браузере.

## Тесты

